# 프로젝트 요구사항과 제출 기준

## 필수 제출물

1. GitHub 저장소
2. 최종 보고서(`.docx` 또는 `.pdf`): 본문 11pt, 최대 20페이지
3. 필수 폴더: `experiment/`, `skill/`, `report/`

## 반드시 증명해야 하는 내용

- ChEMBL 등 화합물 라이브러리의 출처와 분석 범위
- 질병, 타겟 단백질, PDB 구조의 선정 이유
- 타겟 결합/활성, 물리화학적 특성, ADMET을 기준으로 후보를 좁힌 실제 과정
- 모델별 선택 이유, 모델 버전·입력·설정·실행 환경
- 최종 후보의 분자 구조와 선택 근거
- 선택적으로 REINVENT 등 생성 모델을 사용했을 경우 탐색 확장 방법과 결과

## 채점에 대응하는 저장소 원칙

| 평가 요소 | 저장소에서 보이는 증거 |
|---|---|
| 모델 활용 다양성 | 역할별 모델 선정 근거와 실제 실행 메타데이터 |
| 보고서 가독성 | `experiment/figures/`의 Matplotlib 그림 및 간결한 표 |
| Skill·재현성 | `skill/SKILL.md`, 증거 연결표, 원본 CSV와 실행 설정 |
| 추가 평가 | 타겟 선정 근거, 구조 다양성 또는 화학 공간 확장 기록 |

예측 결과는 실험·임상 검증 결과가 아닙니다. 모델이 실행되지 않았거나 결과가 없으면 그 사실을 명시하며 수치를 만들어 채우지 않습니다.
