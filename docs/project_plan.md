# 프로젝트 계획 및 미확정 의사결정

## 현재 단계

제출 구조와 재현성 문서를 준비한 단계입니다. 타겟과 실제 모델 실행은 아직 확정되지 않았습니다.

## 실행 전 결정할 항목

- [ ] 질병과 타겟 단백질
- [ ] PDB 구조 및 사용할 결합 포켓
- [ ] 분석할 화합물 라이브러리의 범위와 추출 조건
- [ ] 계산 환경(CPU/GPU, 메모리, 허용 실행 시간)
- [ ] 활성 예측, ADMET, 도킹에 사용할 모델과 버전
- [ ] 각 필터의 사전 정의된 기준과 최종 순위화 방식
- [ ] REINVENT 등 생성 모델의 사용 여부
- [ ] Solar Pro4로 Skill을 실행하는 방식과 보고서 언어

## 권장 진행 방식

1. 질병·타겟·PDB를 조사하되, 선정 전에는 후보와 근거를 비교 기록합니다.
2. 작은 화합물 샘플을 대상으로 전처리부터 그림 생성까지 한 번 검증합니다.
3. 검증된 설정을 고정하고 전체 범위로 확장합니다.
4. 원본 출력과 실패 로그를 보존한 뒤, 증거 파일을 연결하는 Skill로 Solar Pro4 보고서를 생성합니다.
