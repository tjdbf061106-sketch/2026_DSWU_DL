# 방법 및 판단 로그

_개인적 내부 사고 기록이 아니라, 결론을 점검·반박할 수 있는 재현 가능한 방법과 결정 근거를 기록한다._

---

## 📋 절차

1. 저장소의 필수 폴더, Solar Pro4 Skill, 기존 벤치마크를 감사했다.
2. ChEMBL 공식 API에서 총 활동 수와 엄격한 IC50/Ki/Kd count를 조회했다.
3. 전체 활동 페이지를 받지 않았으므로 고유 화합물 수는 `not_measured`로 유지했다.
4. 상위 5개는 RCSB에서 대표 구조의 방법·해상도·비고분자 리간드를 확인했다.
5. CPU 5코어 ADMET-AI/GNINA 실측을 규모 추정의 기준으로 사용했다.

## ⚠️ 해석 규칙

- 활동 레코드 수는 고유 화합물 수나 모델 일반화 성능이 아니다.
- 결합 리간드 구조는 재도킹의 출발점일 뿐 성공 보장이 아니다.
- 예측값은 임상 효능이나 안전성의 확정값이 아니다.
- NMDA/GABA-A처럼 다중 소단위 수용체는 단일 표적 ID·구조 상태를 먼저 확정해야 한다.

## 🎯 BACE1 설계

`ChEMBL 정리 → target QSAR/GNN → ADMET/BBB → BACE2 선택성 → 다양성 샘플링 → 상위 200~500 GNINA → 선택적 REINVENT → Solar Pro4 보고서`

RDKit 물성 계산은 보조 계산이며 딥러닝 모델 수로 중복 계산하지 않는다.
