# 재현용 요청 명세

저장소의 virtual-screening 파이프라인과 요구사항을 감사하고, 최종 확정 전 27개 질환·타겟 후보를 독립적으로 평가한다.

- ChEMBL API와 RCSB PDB로 target ID, 활동 레코드, 엄격 IC50/Ki/Kd, 구조·리간드 상태를 조사한다.
- 확인하지 못한 수치와 고유 화합물 수는 생성하지 않고 `미검증`으로 쓴다.
- GNINA, logS/logP, ADMET, BBB, QSAR/GNN, 선택성, REINVENT의 역할을 중복 없이 평가한다.
- 로컬 자원과 GNINA 5코어 단일 리간드 실측 2.67초를 반영하되 일반 성능으로 과장하지 않는다.
- 27개 비교표, TOP 5, 최종 1개, 위험 후보, 구체적 실행 설계를 제시한다.
- 질병·타겟을 자동 확정하거나 대규모 실험을 시작하지 않는다.
