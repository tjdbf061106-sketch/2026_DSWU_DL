# 실제 실행 증거 저장소

이 폴더에는 모델로 **실제로 계산한** 결과만 저장합니다. 실행 전에는 아래 파일을 만들지 않거나, 문서에 계획 상태임을 기록합니다.

| 파일 | 작성 시점 | 필수 내용 |
|---|---|---|
| `inputs_manifest.csv` | 입력 확정 후 | 출처, 버전, 검색 조건, 추출일, 포함 수 |
| `screening_results.csv` | 예측 후 | 분자 ID, SMILES, 모델별 예측값, 실행 식별자 |
| `filtering_summary.csv` | 필터링 후 | 단계, 기준, 전후 후보 수, 제외 사유 |
| `candidate_ranking.csv` | 최종 선정 후 | 순위, 후보 ID, 선정·제외 근거, 한계 |
| `run_metadata.json` | 모든 실행 | 모델 버전, 시드, 환경, 명령, 설정 파일, 실패 정보 |
| `figures/` | 시각화 후 | CSV와 연결되는 Matplotlib 그림 |

각 표의 열 정의와 판단 기준은 보고서에서 설명 가능해야 합니다. 비어 있는 값은 실제 누락 또는 미실행으로 구분하여 기록합니다.
